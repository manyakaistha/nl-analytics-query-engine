THE QUIET WORK UNDERNEATH

Built to be understandable.

01

Data loads once.

At startup, the app validates 50,000 synthetic order lines and nine regional monthly targets. DuckDB loads source CSVs with decimal money fields, creates the revenue view, then disables external access.

scripts/validate_data.py · app/database.py
02

Recovery has a limit.

Malformed output and correctable SQL errors can trigger a bounded retry. By default, a question gets at most two generation attempts. Unsafe SQL, resource limits, and access/quota failures stop the pipeline.

app/engine.py · app/llm.py
03

History stays with you.

Recent conversations live in browser session storage. The answer cache is scoped to the session, model, prompt and dataset. Feedback uses temporary receipts; there is no public global query history.

static/history-dock.js · app/cache.py
